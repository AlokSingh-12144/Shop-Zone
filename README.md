# 🛍️ ShopZone — Modern E-Commerce SPA

A sleek, fully responsive **Single Page Application** (SPA) built with **React + Vite**, simulating a real-world e-commerce experience. ShopZone features live product data, cart management with local storage persistence, protected routes, and a polished UI powered by custom CSS.

---

## ✨ Features

- 🏠 **Home Page** — Hero section with stats, popular categories, and featured products
- 📦 **Product Details** — Detailed product view with add-to-cart functionality
- 🛍️ **Cart** — Manage items, update quantities, and view totals
- 🔐 **Authentication** — Login/logout with protected route for Checkout
- 💳 **Checkout** — Multi-step checkout form (protected, login required)
- 📬 **Contact Page** — Customer support contact form
- 🔔 **Toast Notifications** — Instant feedback on cart and auth actions
